Ukládání a správa dat

Jak se data uchovávají a organizují

Úložná média

Data je potřeba nějakým způsobem uložit. Existuje více typů paměti a úložných zařízení, které se liší kapacitou, rychlostí a cenou.

Typy paměti v počítači

  • RAM (Random Access Memory): Operační paměť, velmi rychlá, ale ztrácí obsah při vypnutí
  • ROM (Read-Only Memory): Trvalá paměť, určena pro základní instrukce počítače
  • Cache: Velmi rychlá paměť procesu pro nejčastěji používaná data
  • VRAM: Paměť grafické karty pro ukládání grafických dat

Trvalá úložiště

  • HDD (Hard Disk Drive): Mechanické úložiště, velká kapacita, pomalejší než SSD
  • SSD (Solid State Drive): Elektronické úložiště, velmi rychlé, bez mechanických částí
  • USB flash disk: Přenosné úložiště, malé, ale dostatečné pro přenos souborů
  • SD karty: Malé úložiště v kamerách, telefonech a dalších zařízeních
  • Cloud úložiště: Data uložená na vzdálených serverech (Google Drive, OneDrive, Dropbox)

Organizace dat

  • Souborový systém: Způsob, jak OS organizuje soubory do adresářů (NTFS, FAT32, ext4)
  • Databáze: Strukturované uložiště dat s možností vyhledávání (relační databáze, NoSQL)
  • Indexování: Vytváření rejstříků pro rychlejší vyhledávání
  • Komprese: Zmenšení velikosti dat bez ztráty (ZIP, RAR) nebo se ztrátou (JPEG, MP3)

Správa dat

  • ✓ Zálohování - vytváření kopií důležitých dat
  • ✓ Archivace - dlouhodobé skladování starých dat
  • ✓ Defragmentace - reorganizace dat na disku pro lepší výkon
  • ✓ Kontrola integrity - ověření, že data nejsou poškozena
  • ✓ Metadata - informace o datech (autor, datum vytvoření, velikost)

Databázové systémy

  • Relační databáze: Klasické databáze s tabulkami a relacemi (MySQL, PostgreSQL, SQL Server)
  • NoSQL databáze: Moderní databáze bez pevné struktury (MongoDB, Redis, Cassandra)
  • Graph databáze: Databáze pro uložení grafů a vztahů (Neo4j)
