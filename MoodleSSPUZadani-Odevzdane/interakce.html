Jak si programy vyměňují informace

Komunikace mezi programy

Moderní počítače obsahují spoustu programů, které mezi sebou komunikují a sdílí data. Existuje více způsobů, jak si mohou programy vyměňovat informace.

API (Application Programming Interface)

  • REST API: Webové rozhraní pro komunikaci přes HTTP protokol (nejčastěji používané)
  • GraphQL: Novější jazyk pro dotazování dat s přesnou kontrolou
  • SOAP: Starší standard pro web services (dnes méně používaný)
  • WebSocket: Obousměrné spojení pro real-time komunikaci

Jednotlivá rozhraní (Interfaces)

  • Grafické uživatelské rozhraní (GUI): Interakce přes okna, tlačítka, formuláře
  • Příkazový řádek (CLI): Interakce přes textové příkazy
  • Web rozhraní: Interakce prostřednictvím webového prohlížeče
  • Voice interface: Interakce hlasem (Alexa, Google Assistant)

Typy komunikace

  • Synchronní komunikace: Program čeká na odpověď (telefonní hovor)
  • Asynchronní komunikace: Program nemusí čekat (email, zprávy)
  • Publish-Subscribe: Programy se přihlašují k odběru informací (event-driven)
  • Queue (fronta): Zprávy se zařazují do fronty ke zpracování

Síťová komunikace

  • TCP/IP: Základní protokol pro komunikaci na internetu
  • HTTP/HTTPS: Protokol pro web (bezpečný je HTTPS)
  • FTP: Protokol pro přenos souborů
  • SMTP/POP3/IMAP: Protokoly pro email
  • SSH: Bezpečné připojení na vzdálené servery

Middleware a integrační nástroje

  • Message brokers: Programy, které řídí komunikaci mezi aplikacemi (RabbitMQ, Apache Kafka)
  • ESB (Enterprise Service Bus): Komplexní řešení pro integraci aplikací v podnicích
  • Webhooks: Automatické notifikace mezi systémy při změně dat
  • RPC (Remote Procedure Call): Volání funkcí vzdálených programů

Formáty výměny dat

  • JSON: Nejčastěji používaný formát pro API (čitelný a kompaktní)
  • XML: Starší formát, stále používaný v některých systémech
  • Protocol Buffers: Binární formát pro efektivní komunikaci
  • MessagePack: Kompaktní binární formát
